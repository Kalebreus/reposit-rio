## Como executar

Instale uma versão LTS do [Node.js](https://nodejs.org/). Não é necessário instalar dependências para esta aula.

No terminal, clone o repositório e entre na pasta:

```bash
git clone https://github.com/Kalebreus/reposit-rio.git
cd reposit-rio
```

Execute os exemplos da primeira aula:

```bash
node javascript/01-variaveis-console-template-literal/exemplos.js
```

Os exemplos que provocariam erros estão comentados e acompanhados de explicações.
